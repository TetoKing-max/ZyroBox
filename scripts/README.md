# Zyro Box

Reproductor de música personal para Android, con mi propio nombre, logo, personaje, orden de ajustes y textos en español.

## Crédito y licencia

Zyro Box es una versión modificada de [Mochy Music](https://github.com/realidkroo/Mochy-Music), de realidkroo y sus colaboradores. El proyecto se distribuye bajo la licencia **GPL-3.0** (ver el archivo `LICENSE`), y esa misma licencia aplica a esta versión.

## Compilar

El APK se genera con GitHub Actions: pestaña **Actions** → **CI & Debug Build** → **Run workflow**. El resultado queda en **Artifacts** (`zyro-box-arm64`).
